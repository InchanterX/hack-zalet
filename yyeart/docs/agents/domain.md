# Domain Docs

## Перед изучением кода

- Прочитать `GLOSSARY.md` в корне, если он существует.
- Прочитать относящиеся к работе решения в `docs/adr/`, если они существуют.
- Если этих файлов пока нет, продолжить работу без создания пустых документов.

## Структура

В этом репозитории один доменный контекст. Термины документируются в корневом `GLOSSARY.md`, решения — в `docs/adr/`.

## Терминология и решения

- В задачах, тестах и предложениях использовать термины из глоссария.
- Если нужного термина нет, проверить его по коду и данным; значимый пробел передать в `domain-modeling`.
- Противоречия существующим ADR отмечать явно.
