# Issue tracker: Local Markdown

Задачи и спецификации этого репозитория хранятся в `.scratch/`.

## Структура

- Одна задача верхнего уровня — один каталог `.scratch/<feature-slug>/`.
- Спецификация: `.scratch/<feature-slug>/spec.md`.
- Подзадачи: отдельные файлы `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, начиная с `01`.
- Состояние подзадачи записывается строкой `Status:` в начале файла.
- Комментарии добавляются в конце файла под заголовком `## Comments`.

## Операции

- «Опубликовать в трекере»: создать Markdown-файл в `.scratch/<feature-slug>/`.
- «Прочитать задачу»: открыть файл по переданному пути или номеру.

## Wayfinding

- Карта работы: `.scratch/<effort>/map.md`.
- Дочерняя задача: `.scratch/<effort>/issues/NN-<slug>.md`; тип записывается строкой `Type:`, состояние — `Status:`.
- Зависимости записываются строкой `Blocked by: NN, NN`. Задача доступна, когда все блокирующие задачи имеют `Status: resolved`.
- Следующая задача — первая по номеру открытая, свободная и не заблокированная.
- Перед началом работы установить `Status: claimed`.
- При завершении добавить ответ под `## Answer`, установить `Status: resolved` и добавить ссылку на результат в карту.
