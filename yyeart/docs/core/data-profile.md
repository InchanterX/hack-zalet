Для денег использовался `Decimal`, для дат — `datetime.fromisoformat`; пропуском считалась строка, пустая после `strip()`. Это описание текущего снимка, а не гарантия для будущих выгрузок. Таблицы и поля сопоставлены с [DDL raw](../../../scripts/init/02_raw_ddl.sql).

## Связи и суммы

- Все ссылки заказов на `customer_id` и позиций на товар и продавца разрешаются в текущих CSV. Это проверено сопоставлением множеств ключей из соответствующих файлов таблицы выше.
- У `775` заказов нет позиций, у одного заказа нет платежа, у `768` нет отзыва. Проверка: для каждого `order_id` из `orders` проверено наличие в соответствующем файле.
- Для `639` заказов, имеющих и позиции, и платежи, сумма `price + freight_value` отличается от суммы `payment_value`. Сравнение выполнено суммами `Decimal` по `order_id`; воспроизводящий запрос есть в [журнале решений](decision-log.md#как-проверить-упомянутые-факты-о-csv).
- Сумма `price` позиций вручённых заказов — `13 221 498.11`; сумма `price + freight_value` — `15 424 463.65`. Деление второй суммы на `96 478` вручённых заказов даёт средний чек `159.88` после округления. [D05](decision-log.md#d05-выручка), [D16](decision-log.md#d16-средний-чек).
- При группировке позиций вручённых заказов по `(order_id, product_id, seller_id)` получено `100 196` товарных строк из `110 197` единиц. На `96 478` заказов это `1.04` строки и `1.14` единицы в среднем. [D18](decision-log.md#d18-строка-и-единица-товара).
- При группировке `price` вручённых позиций по продавцу максимум равен `226 987.93`; по исходному коду категории с переводом только для отображения получено `74` категории, максимум `1 233 131.72`, общая сумма `13 221 498.11`. Это прямой расчёт из [CSV заказов](../../../data/olist_orders_dataset.csv), [позиций](../../../data/olist_order_items_dataset.csv), [товаров](../../../data/olist_products_dataset.csv) и [переводов](../../../data/product_category_name_translation.csv); он совпадает с контрольными значениями [tasks.md](../tasks.md).
- Для периода сентябрь 2016 — август 2018 построен полный список из 24 календарных месяцев; после группировки цен вручённых позиций нулевая выручка у ноября 2016, сумма периода `13 221 498.11`. Источники: [CSV заказов](../../../data/olist_orders_dataset.csv), [позиций](../../../data/olist_order_items_dataset.csv), [tasks.md](../tasks.md).

Диагностические запросы к `raw` приведены в [журнале решений](decision-log.md#как-проверить-упомянутые-факты-о-csv). Итоговые аналитические запросы должны обращаться к `core` согласно [заданию](../handout.md).
