# Нормализованная модель `core`

**Статус:** принято для личного решения; команда из пяти участников ещё не сравнивала варианты.

По запросу «согласно документации, выполни задание» выбран [вариант A](../core/proposal-normalized.md): атомарные таблицы сохраняют уровни исходных заказов, единиц товара, платежей и отзывов, а итоги вычисляются в запросах. [Вариант B](../core/proposal-dimensional.md) предрассчитывает суммы заказа, но для выручки продавца и категории всё равно требует атомарные позиции и добавляет сверку дублированных итогов. Основание выбора и происхождение запроса записаны в [D19](../core/decision-log.md#d19-выбор-архитектуры-для-личного-решения) и [сравнении](../core/comparison.md).
