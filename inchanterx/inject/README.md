# inject/ — SQL-патчи к raw из условий вброса

Единственное место, где решение меняет `raw`, и только когда этого требуют
организаторы (PLAN.md, 6.7). Обычно папка пуста.

- Имя файла: `NN_<описание>.sql`, применяются по порядку имён.
- Первая строка файла — комментарий со ссылкой на условие вброса (раздел `../docs/tasks.md`).
- Чистый SQL без `BEGIN`/`COMMIT` и без psql-команд: стадия `raw` выполняет все патчи
  одной транзакцией сразу после загрузчика организаторов и только после этого
  записывает отпечаток в `ops.raw_state`.
- Файлы входят в отпечаток raw: добавление или правка патча вызывает перезаливку raw.
